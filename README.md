# Airport Modelling Project 

A Spring Boot application that simulates airport operations, providing a real-time tabular view and statistical output. 

## Prerequisites: 
- Java 25
- Maven 

## Running the project
While on the project root directory, run the command: 
```
.\mvnw.cmd spring-boot:run 
```
Then, open your browser and navigate to http://localhost:8080. 

## Saved Data 
The application automatically creates a data/ folder in the project root directory when the application is first run.

Files are saved to: 
- data/configtemplates/ - saved configuration templates
- data/results/ - saved simulation results
